# Student Data Organizer

## Project Description
The Student Data Organizer is a Python-based project used to manage student information. It allows users to add, display, update, and delete student records.

## Features
1. Add Student
2. Display All Students
3. Update Student Information
4. Delete Student
5. Display Subjects Offered
6. Exit

## Student Details
- Student ID
- Name
- Age
- Grade
- Date of Birth
- Subjects

## Python Concepts Used
- List
- Dictionary
- Tuple
- Set
- While Loop
- For Loop
- If-Elif-Else Statements
- User Input
- Type Conversion
- CRUD Operations

## How It Works
- **Add Student:** Takes student details and stores them in a list.
- **Display All Students:** Displays all stored student records.
- **Update Student:** Updates the age and grade using the Student ID.
- **Delete Student:** Removes a student record using the Student ID.
- **Display Subjects:** Displays all unique subjects offered by the students.
- **Exit:** Terminates the program.

## How to Run
1. Install Python on your computer.
2. Save the Python code as `student_data_organizer.py`.
3. Open the terminal in the project folder.
4. Run the following command:

```bash
python student_data_organizer.py
```

## Data Storage
The student records are stored temporarily in a list while the program is running. The records are not saved permanently after the program closes.
